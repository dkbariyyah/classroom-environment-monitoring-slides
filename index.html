Project Objectives & Problem Statement

Addressing indoor air quality monitoring challenges using scalable IoT architecture

The Problem

  • Silent Health Risks: Hazardous gas leakage (LPG, smoke, CO) often goes unnoticed indoors until critical thresholds are crossed.
  • Lack of Remote Access: Traditional stand-alone alarms lack real-time cloud dashboard visibility and historical trends.
  • No Remote Intervention: Standard alarm systems do not allow facility managers to remotely silence or test buzzers over Wi-Fi.
Requires automated threshold triggers + instant mobile notifications.

Key Objectives

  • Real-Time Sensing: Continuously monitor temperature, humidity, and gas concentration with 15-second telemetry uploads.
  • Audiovisual Feedback: Implement local Red/Green status LEDs and an audible buzzer for immediate onsite warning.
  • Bidirectional Control: Utilize Favoriot MQTT RPC downlinks to control the local buzzer via a web dashboard switch.
Automated Telegram Bot alerts trigger when AQI threshold > 200.

Red LED Anode (+) GPIO 26 Active when AQI > 200
Green LED Anode (+) GPIO 27 Active when AQI ≤ 200
Power Rail VCC / GND VIN (5V) & GND Power for MQ-2 heater

Critical Wiring Notes

  • ADC1 Pin Requirement: MQ-2 must use GPIO 36 (ADC1). ADC2 pins (e.g., GPIO 4, 12, 14) are disabled when Wi-Fi is active.
  • 5V Power for MQ-2: Connect MQ-2 VCC to VIN (5V) so the internal heating element functions correctly.
analogSetAttenuation(ADC_11db); // Enables full 0V - 3.3V ADC range

// Build JSON telemetry payload
String jsonPayload = "{\"device_developer_id\":\"" + String(device_developer_id) + "\","
                    + "\"data\":{"
                    + "\"temperature\":" + String(temperature, 1) + ","
                    + "\"humidity\":" + String(humidity, 1) + ","
                    + "\"air_quality\":" + String(airQuality) + ","
                    + "\"led_status\":\"" + ledStatus + "\""
                    + "}}";

// Publish to Favoriot stream topic
client.publish(pub_topic.c_str(), jsonPayload.c_str());
